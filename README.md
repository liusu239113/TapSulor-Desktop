## ✨ 功能

- 📊 **收入概览** — 总收入、月度趋势
- 📥 **下载统计** — 各应用下载量变化
- 🔔 **更新检查** — 启动自动检测新版本
- 🎨 **像素风格** — 复古像素风 UI
- 🖥️ **桌面体验** — Electron 原生窗口，支持 Windows 通知

## 🛠️ 开发与构建

```bash
# 安装依赖
npm install

# 本地调试
npm start

# 打包（安装版 + 便携版）
npm run dist

# 仅打包安装版
npm run build

# 仅打包便携版
npm run build:portable
```

产物输出到 `dist/` 目录。
